# ADR-0001：デモ版はブラウザ完結の静的サイトにし、新リポジトリから GitHub Pages で公開する

- 日付：2026-10-11
- 状態：採用

## 背景
PoC本体は Firebase・Cloud Functions・Python 最適化で動き、デモ環境の更新にもデプロイ手順と費用がかかる。
初回デモでは「触ってもらい、割当の考え方を集めて、すぐ直す」サイクルを速く回したい。PoC本体の α版（10月末）は止めたくない。

## 選択肢
1. 案A：PoC本体の Firebase デモ環境をそのまま使う
2. 案B：PoC本体のモノレポに `apps/demo` を足し、Pages で公開する
3. 案C：新リポジトリに画面と純粋関数を写し、localStorage 保存・Web Worker 最適化で Pages に公開する

## 決定
案C。

## 理由とトレードオフ
- 得るもの：push だけで数分で公開。費用0円。ログイン不要で URL を渡すだけ。PoC本体の CI・規約（Firestore ルールなど）に縛られず速く試せる
- 失うもの：記録・勤怠・位置は見せられない。PoC本体とのコードの二重管理（写した元のコミットを各ファイルに書き、11月に揃え直す）。GitHub Free では Pages に**公開リポジトリ**が要る → 架空データ以外を置かない

## 影響
- PoC本体の AGENTS.md の「orgs/{orgId} 配下」「Callable」などの規約はこのリポジトリには適用しない（AGENTS.md に明記）
- デモで固まった仕様（相性・特性・希望）は PoC本体の PRD に戻し、PoC本体側で実装し直す
- 見直す条件：記録・勤怠もデモで見せる必要が出たとき → 案A に戻す
