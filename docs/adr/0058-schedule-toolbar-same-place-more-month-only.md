# ADR-0058：予定の操作の行を日・週・月で同じ位置にし、「その他 ▾」は月だけにする

- 日付：2026-10-23
- 状態：採用
- 関連：PRD D344（D327 の操作の行を書き直し。D334 は今のまま）、ADR-0054（予定の共通の部品）・ADR-0045（操作の行の「その他 ▾」）

## 背景
- ADR-0054 で日・週・月は同じ操作の行（欠勤・キャンセルを登録／AI で組む ▾／元に戻す・やり直す／表示／その他 ▾）を使うようにした
- それでも日の予定だけ、操作の行が「今の担当」の1行・担当ごとの1日（〈スタッフ〉の数だけの横棒）・あるときだけの帯の下にあり、週・月より大きく下にずれていた。［月｜週｜日］を切り替えると「欠勤・キャンセルを登録」などのボタンの位置が変わる
- 「その他 ▾」の中身は、日が「訪問を追加」「使い方」の2つ、週が「週の予定をメールで送る」の1つ（表の上に同じボタンがある）だけ。たたむほどの数が無く、1回余計に押させていた

## 選択肢
1. 案A：今のまま
2. 案B：日の操作の行を「今の担当」の1行のすぐ下へ上げ（週の1行の状態・月の進み具合の帯の下と同じ位置）、日・週の「その他 ▾」をやめて中身を出す（月は項目が多いので残す）
3. 案C：3画面とも見出しのすぐ下（状態の1行より上）に操作の行を置く

## 決定
案B。
- 日：操作の行は `plan-summary`（今の担当の1行）のすぐ次。担当ごとの1日・あるときだけの帯・提案の帯はその下
- 日（601px 以上）：「訪問を追加」（`plan-visit-add`。押せないときは `aria-disabled` と title に理由）・「使い方」（`plan-help-btn`。`aria-pressed`。開くと説明 `plan-help`）を操作の行のボタンにし、「その他 ▾」（`plan-more`）は出さない。新しい訪問の欄を閉じたらフォーカスは「訪問を追加」へ
- 日（600px 以下）：今のまま「その他 ▾」に訪問を追加（押せない）・表示（日ごとのリスト・順番・一覧）・使い方（D334。操作の行は1段）
- 週：「その他 ▾」（`week-more`）を出さない。メールで送るは表の上のボタン
- 月：今のまま（表示を選ぶ・印刷・勤務の見込み・マスの見方の説明）

## 理由とトレードオフ
- 得るもの：［月｜週｜日］を切り替えても操作の行がほぼ同じ高さにあり、押す所を探さない。日の「訪問を追加」・「使い方」が1回で押せる。週の重なったメニューが消える
- 失うもの：日の操作の行のボタンが2つ増える（広い画面では1段に収まる）。案C は状態の1行が操作の行の下になり、ADR-0054 の「見出し→状態→操作の行」の並びを崩すので取らない

## 影響
- `src/pages/PlanPage.tsx`（操作の行の位置・訪問を追加と使い方のボタン）・`src/pages/WeekPage.tsx`（その他 ▾ をやめる）
- e2e：`scripts/e2e-plan-menu.cjs`（日の操作の行の中身・位置・フォーカスの戻り先）・`e2e-schedule-v4.cjs`（その他 ▾ は月だけ）・`e2e-visit-panel.cjs`（訪問を追加は操作の行から）
- 見直す条件：日・週の操作がまた増え、操作の行が1段に収まらなくなったら「その他 ▾」に戻す
