# ADR-0006：Excel の書き出し・読み込み（テンプレートとして編集して入れ直す）

- 日付：2026-10-13
- 状態：採用

## 背景
利用者から「スタッフ・利用者さん・条件などを Excel で一覧にして、それをテンプレートとして追加・修正し、読み込めば内容が全部変わるようにしたい」という要望が出た。今の書き出し（D3）は版付き JSON で、人が直接編集するものではない。

決めること：(1) Excel に何を入れ、読み込みで何を置き換えるか、(2) シートどうしの参照の書き方、(3) Excel を扱うライブラリ。

## 選択肢
1. 案の扱い
   - A：Excel にはマスタと予定だけを入れ、読み込んだら案（AI案・記録・手作業案）は消す
   - B：ID が一致する人・訪問の案は残す
2. 参照の書き方
   - A：名前で書く（ID 列も残し、空なら新しい行）
   - B：ID で書く
3. ライブラリ
   - A：ExcelJS（npm で保守が続く。見出しの色・列幅・入力規則を付けられる）
   - B：SheetJS（軽い。npm の版は古く、新しい版は公式 CDN から入れる必要がある）

## 決定
1-A、2-A、3-A（利用者が選んだ。2026-10-13）。

## 理由とトレードオフ
- 得るもの：
  - Excel で行を足す・直すだけでデータを入れ替えられる
  - 名前で書くので、手で書き足しやすい
  - 見出し・プルダウン付きのテンプレートとして渡せる
  - 案を消すので、古い案と新しいマスタが食い違わない
- 失うもの：
  - 読み込むと案は消える（丸ごとの控えは今までどおり JSON で取る）
  - 同じ名前の人・項目は読み込みで止める（名前は一意にしてもらう）
  - ExcelJS のぶん、画面のファイルが重くなる（Excel の画面を開いたときだけ読み込む動的 import にする）

## 影響
- PRD：D23 を足す。「やらないこと」の CSV（記録・実証データの出力）とは別物
- design.md：コンポーネント `excel` を足す（`src/excel/`）。§5 にシートの形を書く。データを書き換えるのは今までどおり store だけ（excel は変換するだけで、読み込んだ結果は store の `migrate`→`repair` を通して `replace` する）
- 外部送信は増えない（ライブラリは同梱）
- 見直す条件：ファイルの大きさが問題になったら SheetJS への置き換えを検討する。同名の人が実際に要るなら、参照を ID 併記に変える
