# ADR-0056：訪問の帯の見た目・選ぶ・キーで動かす・ドラッグの落とし先の判定を共通の部品にし、週の表・月のカレンダー・人の予定表でも使う

- 日付：2026-10-22
- 状態：採用
- 関連：PRD D339〜D341（D330・D333 を書き直し）、ADR-0054（予定の共通の部品）・ADR-0055（キーボード・スマホの日ごとのリスト。見直し全体の要約）の続き

## 背景
- 5段の見直し（ADR-0051〜0055）のあとも、日（`PlanPage`）・週（`WeekPage`）・月（`MonthPage`）・人の予定表（`PersonCalendar`）の本体はそれぞれ別に育っていた。共通なのは見出し・操作の行・訪問の詳細の欄・提案の帯・全体の元に戻すだけ
- 困っていたこと：
  - 複数選択（`lib/multiEdit`）とキーで動かす（`lib/visitKeys`）は日と週の時間軸だけ。週の表（〈スタッフ〉×曜日・〈利用者さん〉×曜日）・月のカレンダー・人の予定表ではできない。〈スタッフ〉×曜日の表のマスは3段バーと件数だけで、訪問そのものが無かった
  - 帯の見た目（要対応・ピン・未連絡の変更・資格✗／限✗）が画面ごとに別の計算：日は要対応・ピン・未連絡、週の時間軸と〈利用者さん〉の表は資格✗・限✗だけ、人の予定表はピンと「変」だけ、スマホの日ごとのリストは要対応・未連絡・ピン。レビューで「この画面だけ判定が古い」が何度も出た
  - ドラッグの落とし先の判定も画面ごと（週の時間軸・週の表・人の予定表で、今日より前・時間の幅・同じ行の決まりを別々に書いていた）
- ユーザーの選んだ形：全部を1つの本体にはしない。帯の見た目・選ぶ・キー・落とし先の判定を共通の部品にし、本体（日の時間軸と地図・欠勤の振り直し・差の欄、週の時間軸と表、月のマス、人の予定表）は画面ごとに残す

## 選択肢
1. 案A：日・週・月・人の予定表を1つの本体（拡大率を props）に作り直す
2. 案B：本体は残し、帯の見た目・選ぶ・キー・落とし先の判定を共通の部品（純粋関数＋小さなフックと部品）にして、各画面の帯・行・マスから使う
3. 案C：今のまま、画面ごとに足りない所だけ足す

### 月のマスのキー
1. 案A：マスの中の訪問に直接フォーカス（マスの中で ↑↓）
2. 案B：マスは日を選ぶ単位（←→ 日・↑↓ 週）にし、Enter で「その日の回の一覧」を開き、一覧の行で訪問を選ぶ・動かす

## 決定
どちらも案B。

### 共通の部品（`lib/visitLook`・`lib/visitSelect`・`lib/visitDrop`・`lib/visitKeys` の `cellKeyOf`、`components/visitParts.tsx`）
- **帯の見た目**（PRD D339。`visitLook`・`dayLooks`・`VisitMarks`・`useVisitLooks`）：印は「要対応（!）・資格✗／限✗・未連絡の変更・ピン・この回だけ変更（変）・仮押さえ（仮）」の順。元は日の状態（`useDayStatuses` の `DayStatus.issues`・`told`）とその日の問題の可否（`unfitMarks`）だけ。資格✗・限✗があれば同じことを言う「要対応」の印は重ねない。取り消し・休みの回は未連絡の変更（伝えた訪問が外れる）だけ。今日より前の日は要対応・資格✗／限✗を出さない（月のマス・ホームと同じ）。どの帯・行にも `data-marks`（印の種類）と、読み上げに印の説明を付ける
- **選ぶ**（PRD D340。`useVisitSelection`・`useVisitItem`・`SelectToggle`）：Shift／Ctrl（⌘）＋クリック・Shift／Ctrl＋Enter で1件ずつ、Esc で外す。スマホ（600px 以下）は長押し（500ms）か「選ぶ」で選ぶ形に入り、押すと選ぶ・外す。今日より前・取り消し・休みは選ばない。選んだ訪問は今までの複数選択の帯（`SelectionBar`。担当を替える・時刻をずらす・取り消す）。期間（日・週・月・人と期間）を変えたら外す
- **キーで動かす**（PRD D333・D340。`useVisitKeys`）：どの帯・行も ↑↓ 15分・←→ 1日・Shift+←→ 隣の担当（担当できる人まで飛ばす）・Enter 欄・Delete 取り消し・繰り返しの回の範囲の帯と Alt+↓。期間の外へ動いたらその期間へ移り、フォーカスは動かした帯（`focusVisitItem`）。日時を動かさない所（〈スタッフ〉の画面）は ↑↓←→ を読まない（Shift+←→・Enter・Delete だけ）。スマホではキーを読まない
- **ドラッグの落とし先の判定**（PRD D341。`dropVerdict`・`dropShadowText`・`useVisitDrag`・`DropShadow`）：置けない（訪問が無い・取り消し・休み・今日より前の訪問・今日より前の日・ほかの人の行・7:00〜20:00 の外）は灰の斜線の影と理由（落とせない）。置けるが入らない（入れる人が0人・担当できない人の行）は赤い点線の影と理由（落とせる。落とすと要対応）。入るなら「ここへ（時刻）・入れる人 N人」。確定した日なら「確定した日（変えると未連絡の変更）」、繰り返しの回なら「繰り返しの回（範囲は欄で選ぶ）」を添える。落とすと落とした日時（・担当）を入れた訪問の詳細の欄（範囲・確定した日の確かめは欄）
- **1行1訪問の行**（`VisitRow`）：［選ぶの印］時刻｜名前と担当の印・名前（取り消し・休みの札）｜印。スマホの日ごとのリスト・人の予定表の2段目（日ごとのリスト）・月のその日の回の一覧で同じ

### 画面ごと
- 週の〈スタッフ〉×曜日の表：マスの3段バーの下に、その人のその日の訪問を1行ずつ（時刻・〈利用者さん〉・印）。押すと欄・選ぶ・キー。ほかの人・日のマスへドラッグすると、その日・その人を選んだ欄（担当できなければ赤い影と理由）
- 週の〈利用者さん〉×曜日の表：帯で選ぶ・キー。帯の下の担当の名前のあとに印
- 週の時間軸：帯に印（今までは資格✗・限✗だけ）
- 月のカレンダー：マスで ←→ 前・次の日・↑↓ 前・次の週（月の外へ出たらその月へ）・Enter で「その日の回の一覧」（右の欄の先頭。表示の選択が〈スタッフ〉・〈利用者さん〉ならその人の回だけ。〈利用者さん〉でその日の回が1つならその回の欄）・Shift／Ctrl＋Enter・Shift／Ctrl＋クリックでその日の選べる訪問をまとめて選ぶ・外す（マスに「選択 N」）。押すと今どおりその日の日の予定。一覧の行は選ぶ・キー・ほかの日のマスへドラッグ。一覧の中の Esc（選んでいれば先に選択を外す）・× でマスへ戻る
- 人の予定表：回で選ぶ・キー・印（今まではピンと「変」だけ）。2段目の日ごとのリストの行は `VisitRow`（「選ぶ」と長押し）。〈スタッフ〉の画面は日時を動かさない（キーの ↑↓←→ と複数選択の帯の「時刻をずらす」を出さない）。広い画面の道具の行に全体の「元に戻す」
- 日の予定：時間軸の帯の要対応・資格✗／限✗・未連絡の変更・ピン・この回だけ変更・仮押さえの印を共通の判定から（限✗も出るようになる）。スマホの日ごとのリストの行は `VisitRow`
- 画面ごとに残すもの：日の時間軸と地図・欠勤の振り直し・差の欄（代行・時刻の変化・振り直しの印）、週の時間軸と表の並べ方、月のマス（「休 N」「要対応 N」の札・3段バー）、人の予定表の足す・空き枠
- データを書くのは今までどおり store の update だけ（キーは `applyVisitEdit`・`cancelVisitOp`、選んだ訪問は `lib/multiEdit`、ドラッグは欄の保存）。どの操作も全体の元に戻すの1手（手の名前つき）

## 理由とトレードオフ
- 得るもの：
  - 週の表・月・人の予定表でも、マウスを使わずに訪問を選ぶ・動かす・担当を替える・取り消すができる。スマホでも長押しで選んで担当替え・取り消しができる
  - 同じ訪問の印がどの画面でも同じ（判定の元が1つ）。印の種類を足すときは `visitLook` だけを直せばよい
  - ドラッグで「なぜ置けないか」が影の文で分かり、どの画面でも同じ文
- 失うもの（できなくなる・変わること）：
  - 週の〈スタッフ〉×曜日の表はマスが縦に長くなる（訪問の行が増える。印刷では行を出さない）
  - 月のマスの Enter は日の予定を開かず「その日の回の一覧」を開く（日の予定へは押す・一覧の「この日の日の予定を開く」）
  - 人の予定表の回の aria-pressed は繰り返しの強調ではなく選択を表す（強調は今までどおり色と「薄く」）
  - 〈スタッフ〉の画面の複数選択の帯に「時刻をずらす」は出さない
  - 今日より前の日の帯に要対応の印を出さない（日の予定の時間軸も）
- 手を入れた決まり（推測を含む）：
  - 月のマスの Enter は「〈利用者さん〉を選んでいてその日の回が1つなら欄、ほかは一覧」
  - 月のマスでまとめて選ぶのは、表示の選択が〈スタッフ〉・〈利用者さん〉ならその人の回だけ
  - 〈スタッフ〉×曜日の表のマスへ落としたときは、欄で担当をはじめから選んでおく（候補に無い・選べなければ「変えない」）
  - 置けない影は落とせない（drop を受けない）。入らない影は落とせる

- 残っている課題：
  - 日・週・月・人の予定表の本体は4つのまま（共通は部品だけ）。日の予定の帯の詳細（理由・「担当を変える ▾」）と訪問の詳細の欄の2か所がある
