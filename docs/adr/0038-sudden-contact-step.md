# ADR-0038：欠勤・キャンセルの欄に5段目「連絡」を足し、連絡文のひな形と載せる範囲を決める

- 状態：採用（2026-10-20）
- 関連：PRD D243〜D247（D35・D94・D145・D168 の見直し）、ADR-0011 追記（連絡の一覧）・ADR-0017（メール）・ADR-0025 追記（欠勤・キャンセルの欄・ホーム）

## 背景
欠勤・キャンセルの欄（PRD D167〜D172）は 起きたこと→人→影響→確定 の4段で、確定すると欄が閉じていた。確定のあとに要る「だれに何を伝えるか」は、日の予定の差の欄の「連絡の一覧」（D35）を自分で開かないと見えず、キャンセルでは担当への中止の連絡が一覧に出なかった（取り消した訪問は「入らない（調整中）」に見える）。
連絡文のひな形（敬語の度合い・載せる範囲）は PRD §8 の未決のままで、〈利用者さん〉あての文に前の担当の名前（「山田さんから 佐藤さんに」）が、日付に「本日」が入っていた。
管理者は当日の朝にスマホで欠勤の電話を受けることが多いが、スマホのホームでは入口が「いつでも」の中（画面の下）にあった。

## 選択肢
1. 案A：欄は4段のまま、確定のあとに差の欄の「連絡の一覧」を開く
2. 案B：5段目「連絡」を足し、確定し直した差と取り消した訪問から1人に1行の一覧を出す。［連絡した］は欄の中の状態だけ
3. 案C：案B に加え、［連絡した］を `DemoData` に残す（だれにいつ伝えたか）

## 決定
案B。

- 段階は 起きたこと→休む人（訪問）→影響→確定→連絡。4段目の「この割当で確定」で5段目へ（確定済みで確定し直すものが無ければ「次へ：連絡」）。5段目は「終わる」で閉じる
- 一覧の差は「前の確定した割当 → 新しい割当」。欠勤は振り直しの元の案（確定した割当、無ければ振り直す前の案）→ 今の案（`contactsOf`）、キャンセルは取り消したときの確定した割当 → 今の案と、取り消した訪問（取り消す前の担当・開始）。純粋関数 `lib/contacts` の `contactRows`
- 1人に1行。種類は 担当が外れる・新しく入る・時刻が変わる・中止・〈利用者さん〉あて。キャンセルした〈利用者さん〉には作らない
- 各行に［文をコピー］・〈スタッフ〉あてのメール（`mailto:`。D94 と同じ件名）・［連絡した］。［連絡した］はその場の状態だけ（欄を閉じると消える。印の鍵は宛先と文なので、文が変われば消える）
- キャンセルの差の「前」は、確定した割当を振り直しの元の案と同じ並べ方（`lib/absences` の `orderConfirmed`）にしてから時刻を出す（訪問データの並びのままだと偽の「時刻が変わる」が出る）
- ひな形（D245）：〈スタッフ〉あては丁寧語の短文、〈利用者さん〉あては敬語（名乗り・お詫び・結び）。日付は「10月21日（水）」（「本日」と書かない）、時刻は 9:00（文中は空白なし）。〈利用者さん〉あてはどの訪問かを約束の開始（「9:00」「9:00〜9:30の間」）で書き、新しい開始は「ごろ」（見込みの時刻は約束と違って見えるため）。過ぎた時刻の行も除かない。差の欄の連絡の一覧（D35）も同じひな形にそろえる
- 載せる範囲（D246）：住所・所要は〈スタッフ〉あての「お願いします」の行だけ。〈利用者さん〉あては担当の姓と時刻だけ（前の担当・住所・代わる理由は書かない）
- スマホ（860px 以下）のホームは、欠勤・キャンセルの入口を見出しのすぐ下に置き「いつでも」から外す（D247）。見た目はほかの入口と同じカード（赤い縁は付けない。日の予定の入口と同じ考え）で、アイコンだけ朱

## 理由とトレードオフ
- 得るもの：確定から連絡までが1つの流れで終わり、キャンセルの担当への中止も漏れない。差の欄の一覧と5段目で文が同じ。〈利用者さん〉へ〈スタッフ〉の欠勤や前の担当を伝えずに済む（個人情報を最小に）。［連絡した］をデータに残さないので契約（`src/contracts/`）・データの版・Excel を変えない
- 失うもの：［連絡した］は欄を閉じると消え、あとから「だれに伝えたか」を見返せない（記録・勤怠はやらないことの範囲。PRD §4）。〈利用者さん〉にはメールアドレスが無いのでメールのボタンは出さず、文のコピーだけ。姓は名前の空白の前で取るので、空白の無い名前はそのまま出る。5段目へ進むぶん、確定のあとに「終わる」を1回押す
